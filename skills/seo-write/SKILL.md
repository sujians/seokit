# B2B Technical and Procurement Writing

1. **Read the working files.** Reload `profile/profile.yaml` with `seokit_load_profile({})` and read the complete `drafts/<slug>-brief.md` from disk. If no matching brief exists, run `seo-brief` to create and check one first. Use verified public sources and user materials in generic mode when the profile is unusable. Keep the brief's artifact slug and record its publication path separately.
2. **Confirm scope and claim evidence.** Read [B2B manufacturing writing and phrase review](references/b2b-writing-and-anti-slop.md) and [GEO citation and draft QA](references/geo-citation-and-qa.md). Write established industry methods in full with clear examples. Verify specific public facts such as edition-specific requirements and numerical limits through authoritative sources. Support factory claims only with `profile/profile.yaml` or user-provided materials. For an update, use the verified existing copy to decide what to retain, strengthen, or add. Preserve the existing URL unless a move is approved.
3. **Answer the main search question first.** Follow the brief's intent and use natural headings, complete technical explanations, worked examples, and concise attribution at the point of use. On informational pages, keep at least 80% for core technical content and at most 20% for conversion, preferably 10–15% for conversion. Use a standalone FAQ when recurring questions or concept confusion warrant it. Put it after the technical sections and concise DFM or procurement handoff, just before the closing CTA when present. Place useful tables and figures where they help the reader. Include only useful links as part of a sentence and collect other relevant references in a final sources section. Keep publication metadata with the draft and Schema recommendations with the brief.
4. **Review and revise.** Use the QA checklist and run `seokit_score_geo` on the complete draft body rendered as HTML. Make one automatic improvement pass when direct answers, useful tables, attribution, or link formatting need work, then rescore. Use concise factory placeholders for optional measurements, photos, or customer records and continue to save the working draft.
5. **Save the draft.** Write and read back `drafts/<slug>.md`. Report both paths, the GEO result when available, and open publication items. Pause saving only if missing core product positioning, an unverifiable hard compliance commitment, or serious fabricated data remains after revision and prevents a trustworthy draft. In those cases, preserve the brief and any existing draft and report the affected passage and the information needed.
