# B2B Technical and Procurement Writing

1. **Read the working files.** Reload `profile/profile.yaml` with `seokit_load_profile({})` and read the complete `drafts/<slug>-brief.md` from disk. If no matching brief exists, run `seo-brief` to create and check one first. Use verified public sources and user materials in generic mode when the profile is unusable. Keep the brief's artifact slug and record its publication path separately.
2. **Confirm mode and evidence.** Load [B2B manufacturing writing and phrase review](references/b2b-writing-and-anti-slop.md) to prepare the claim evidence and [GEO citation and draft QA](references/geo-citation-and-qa.md) to map the brief to the draft. For a new page, confirm the intended buyer task and proposed path. For an update, use the current-page inventory and verified source copy to retain, strengthen, or add content as specified. Preserve the existing URL unless a move is approved. Resolve conflicts affecting scope, stated facts, or the buyer's main decision before drafting. Mark missing factory proof, identify what blocks a draft, and keep the brief intact.
3. **Write in the brief's section order.** For each H2/H3, use its buyer question, opening answer, prose budget, and linked term, gap, objection, asset, and evidence IDs. Apply verified target-market terminology, deliver the promised decision aid, and place figures, tables, descriptive internal links, and the CTA where the brief calls for them. Use the two evidence tracks for new and retained claims. Keep publication metadata with the draft and the Schema handoff in the brief.
4. **Review and revise.** Apply every row of the pre-save checklist and run `seokit_score_geo` on the complete draft body rendered as HTML. Make one automatic revision in the working copy for any fixable failure, then repeat the checks and rescore the revised body. A missing factory test or measurement that the central buyer decision still depends on blocks saving.
5. **Save or report the blocker.** After the checks pass, save `drafts/<slug>.md` and read it back. Report both artifact paths, the score, and remaining publication dependencies. If a gate still fails, return the specific blocker and any reviewable text in the response. Preserve the saved brief and any existing draft.
